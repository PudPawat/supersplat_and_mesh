Motivation

3D Gaussian Splatting (3DGS) enables photorealistic real-time novel-view synthesis via splat rasterization — millions of oriented Gaussians sorted and alpha-blended per pixel. Traditional triangle meshes, by contrast, use rasterization with PBR shading and expect depth buffers, normals, or ray-traced environment maps for specular reflections.

The problem: you cannot drop a glossy GLB model into a 3DGS scene and expect correct reflections out of the box. Mesh shaders look for skyboxes, cubemaps, or ray-traced hits — but the splat background is not geometry the mesh renderer understands. Standard mesh ray tracing and SSR pipelines assume conventional triangle depth; 3DGS produces no triangles, no G-buffer, and only an approximate alpha-weighted depth approximation.

Our goal: combine 3DGS rasterization with mesh PBR reflection techniques so reflective objects (cars, glass, metal) can sit inside a splat scene and show the splat environment in their reflections — all in a standard web browser via WebGL.

3DGS (Splat Rasterization)

Fast, volumetric, no mesh geometry pass. Produces color and approximate depth but no conventional surface normals or triangle hits for reflection APIs.

Mesh PBR (Reflection)

Cook-Torrance microfacet BRDF with GGX distribution. Expects environment maps, SSR depth buffers, or ray-traced hits — incompatible with splats without a bridging layer.

Abstract

3D Gaussian Splatting (3DGS) enables photorealistic real-time novel-view synthesis but provides no support for interactive objects or reflective materials. We present a hybrid rendering system that composites reflective 3D mesh objects into a live 3DGS scene by extending the open-source SuperSplat viewer.

Screen Space Reflection (SSR) handles on-screen ray marching while Reflection Probes provide 360-degree fallback coverage; a confidence-based blend merges both sources. The system loads GLB meshes with PBR materials and runs in a standard web browser via WebGL. We extend SuperSplat with a mesh compositing layer, a dual reflection system, and an input dispatcher resolving conflicts between camera navigation and object manipulation in a shared WebGL canvas.

Method

The rendering pipeline executes in four stages: (1) Gaussian rendering draws the 3DGS scene; (2) mesh rendering draws GLB objects depth-tested against the Gaussian depth buffer; (3) SSR pass ray-marches against the combined depth buffer for reflective pixels; (4) reflection blending merges SSR and probe sources via confidence weighting. 

1. Gaussian Rendering   → 3DGS scene (color + approximate depth)
2. Mesh Rendering       → GLB objects, depth-tested against Gaussian depth
3. SSR Pass             → Screen-space ray march for reflective pixels
4. Reflection Blending  → SSR + Probe merged via confidence weighting

Screen Space Reflections (SSR)

After the splat pass, the scene color buffer is snapshotted before mesh objects draw. A custom PlayCanvas shader chunk replaces the standard environment reflection path and ray-marches in screen space each frame — sharp, parallax-correct, but limited to on-screen content.

Reflection Probe (IBL)

Renders the 3DGS scene from the mesh object's position in six cubemap directions, reprojects to equirectangular format, and builds a prefiltered specular atlas. Injected into GLB StandardMaterial instances via envAtlas without replacing original textures.

SSR assigns each pixel a confidence value (1.0 = successful hit, 0.0 = miss). The final reflection is:

Reflection = Confidence × SSR_color + (1 − Confidence) × Probe_color

For imported GLB files, we preserve all original PBR properties and only set envAtlas and useSkybox = false on the author's materials.

Performance

Tested on NVIDIA RTX 3060 (Chrome) and Apple M1 (Safari) with ~1.2M-Gaussian indoor and outdoor scenes. SSR iterations: 64; probe resolution: 256×256.

Configuration SSR Probe Laptop FPS M1 FPS

High-polygon meshes with SSR remain interactive (~62 fps on laptop). Probe-only mode is the cheapest reflection option.

Code & Quick Start

git clone https://github.com/PudPawat/supersplat_and_mesh.git
cd supersplat_and_mesh
npm install
npm run develop

# Open http://localhost:3000
# 1. Load a .ply splat scene
# 2. Click the Mesh tab in the bottom bar
# 3. Import GLB or load the Audi R8 sample
# 4. Adjust material presets and re-capture reflection
